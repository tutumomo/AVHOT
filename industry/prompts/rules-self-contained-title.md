
【標題自洽規則 — 讓讀者不點開就知道"這是關於誰的什麼事"】

1. 標題必須點出核心主體：片商或廠牌名 / 作品名與番號 / 出演者名 / 平臺名。
2. 原標題已經清楚點出主體的：英文標題翻譯成中文、中文標題保持原意，不要為改寫而改寫。
3. 原標題只是番號 / 系列名 / 沒資訊量的 teaser（如 "SSIS-123"、"【新作】"、"Day 1"、"解禁"）時，結合【來源】和正文把主體補進標題。例：原標題 "SSIS-123" + 來源 "S1 官方" → "S1 新作 SSIS-123 公佈發售資訊"。
4. 補主體只能用【來源】或正文裡真實出現的名字。正文和來源都沒點出具體片商或作品名時，用上位詞（如"某廠牌新作"）兜底，絕不憑"行業常識"編一個具體的片商、番號或數字。
5. 原標題表達的【文章型別和核心動作】是硬邊界：How / Why / Guide / Analysis / Review / Benchmark 這類解釋、分析、教程或評測標題，中文標題必須保留這個型別；不能因為正文談到一個已經存在的模型、產品或新資料，就改寫成“釋出 / 推出 / 上線 / 開源”。只有原標題明確宣佈了釋出、推出、上線或開源，中文標題才能使用對應動作。保留文章型別不等於刪主體：仍須按第 1-4 條補全正文或來源明確給出的公司、產品、專案名。
   例：原標題 "How the new VR workflow changes production" → "新 VR 製作流程如何改變拍攝"，不能寫成 "某片商釋出 VR 新作"。
   例：原標題 "How to choose a streaming plan" + 來源和正文明確是 FANZA → "FANZA 的訂閱方案怎麼選"，不能只寫成缺主體的 "訂閱方案怎麼選"。
