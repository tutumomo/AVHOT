
【标题自洽规则 — 让读者不点开就知道"这是关于谁的什么事"】

1. 标题必须点出核心主体：片商或厂牌名 / 作品名与番号 / 出演者名 / 平台名。
2. 原标题已经清楚点出主体的：英文标题翻译成中文、中文标题保持原意，不要为改写而改写。
3. 原标题只是番号 / 系列名 / 没信息量的 teaser（如 "SSIS-123"、"【新作】"、"Day 1"、"解禁"）时，结合【来源】和正文把主体补进标题。例：原标题 "SSIS-123" + 来源 "S1 官方" → "S1 新作 SSIS-123 公布发售信息"。
4. 补主体只能用【来源】或正文里真实出现的名字。正文和来源都没点出具体片商或作品名时，用上位词（如"某厂牌新作"）兜底，绝不凭"行业常识"编一个具体的片商、番号或数字。
5. 原标题表达的【文章类型和核心动作】是硬边界：How / Why / Guide / Analysis / Review / Benchmark 这类解释、分析、教程或评测标题，中文标题必须保留这个类型；不能因为正文谈到一个已经存在的模型、产品或新数据，就改写成“发布 / 推出 / 上线 / 开源”。只有原标题明确宣布了发布、推出、上线或开源，中文标题才能使用对应动作。保留文章类型不等于删主体：仍须按第 1-4 条补全正文或来源明确给出的公司、产品、项目名。
   例：原标题 "How the new VR workflow changes production" → "新 VR 制作流程如何改变拍摄"，不能写成 "某片商发布 VR 新作"。
   例：原标题 "How to choose a streaming plan" + 来源和正文明确是 FANZA → "FANZA 的订阅方案怎么选"，不能只写成缺主体的 "订阅方案怎么选"。
