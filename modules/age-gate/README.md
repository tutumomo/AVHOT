# age-gate：18+ 年龄闸门

成人内容站在大多数主机商、广告商和支付渠道那里都要求年龄确认。这个模块给全站加一道 18+ 闸门：读者确认后把选择写进这台浏览器的 localStorage，之后不再出现。

- 只在前端：不改引擎的页面、接口、缓存和数据库；RSS、公开 API 与 MCP 这些机器出口不受影响。
- 绘制前就挡住内容（`root.bootScript`），不会先闪出正文；闸门本身由 `root.Bottom` 渲染。
- 后台 `/admin` 不挡。
- 脚本没跑起来时 10 秒后自动撤掉遮挡，避免留下一张白页。

## 它不是身份验证

这是**自述式**确认，和所有仅靠前端的年龄闸门一样，只能拦住顺手访问的人，不能证明年龄。按你的运营地判断是否需要更强的措施（服务端闸门、信用卡或证件验证、按地区限制）。要求更严的市场通常还需要在反向代理或 CDN 层做地域判断。

## 改文案与行为

- 版本号在 `web.tsx` 的 `STORAGE_KEY` 里（`avhot.age-confirmed.v1`）：改了闸门含义就升一位，读者会重新确认。
- 文案在 `AgeGate` 组件里；离开时跳转的地址在 `leave()` 里，默认回 Google。
- 站点名取 `SITE.name`，不要在这里写死。

## 停用

从 `site/modules/web.ts` 的清单里去掉 `ageGateWeb`，再从 `site/package.json` 的 `dependencies` 去掉 `@aihot/age-gate`，重新构建即可。所有行为都在这个文件夹里，删掉文件夹不影响引擎。
