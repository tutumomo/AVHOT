# age-gate：18+ 年齡閘門

成人內容站在大多數主機商、廣告商和支付渠道那裡都要求年齡確認。這個模組給全站加一道 18+ 閘門：讀者確認後把選擇寫進這臺瀏覽器的 localStorage，之後不再出現。

- 只在前端：不改引擎的頁面、介面、快取和資料庫；RSS、公開 API 與 MCP 這些機器出口不受影響。
- 繪製前就擋住內容（`root.bootScript`），不會先閃出正文；閘門本身由 `root.Bottom` 渲染。
- 後臺 `/admin` 不擋。
- 指令碼沒跑起來時 10 秒後自動撤掉遮擋，避免留下一張白頁。

## 它不是身份驗證

這是**自述式**確認，和所有僅靠前端的年齡閘門一樣，只能攔住順手訪問的人，不能證明年齡。按你的運營地判斷是否需要更強的措施（服務端閘門、信用卡或證件驗證、按地區限制）。要求更嚴的市場通常還需要在反向代理或 CDN 層做地域判斷。

## 改文案與行為

- 版本號在 `web.tsx` 的 `STORAGE_KEY` 裡（`avhot.age-confirmed.v1`）：改了閘門含義就升一位，讀者會重新確認。
- 文案在 `AgeGate` 元件裡；離開時跳轉的地址在 `leave()` 裡，預設回 Google。
- 站點名取 `SITE.name`，不要在這裡寫死。

## 停用

從 `site/modules/web.ts` 的清單裡去掉 `ageGateWeb`，再從 `site/package.json` 的 `dependencies` 去掉 `@aihot/age-gate`，重新構建即可。所有行為都在這個資料夾裡，刪掉資料夾不影響引擎。
