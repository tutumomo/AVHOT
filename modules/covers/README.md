# covers：官方封面與官方頁連結

成人影片站的重點是封面，但商品頁會把站方自己的界面圖示（DUGA 的評分星等 gif、裝置支援 svg）和作品封面
一起塞進 HTML，抽取時封面常常排在第十一張。這個模組做兩件事：

1. **清 media**：每天 04:50 掃最近四天的資料，把界面圖示挑掉、封面排到第一張（`clean.ts`）。
   只動真的變了的列，重複執行沒有副作用。
2. **封面欄**：在首頁與「全部動態」最上面顯示一排「最新作品與官方封面」，每張連到站內條目頁，
   旁邊一個「官方頁 ↗」連到來源的官方頁（`web.tsx` + `/api/covers/recent`）。

## 它不碰版權預設

正文照舊只有摘要與原文連結（信源的 `site_fulltext` 仍是關的）。這一欄顯示的是**各官方頁面上的作品封面**，
附回官方頁的連結 —— 和站內其他地方一樣，圖只經本站的圖片代理顯示，不重製檔案。

## 公開範圍仍由讀取層決定

`/api/covers/recent` 的候選清單來自 `packages/backend/src/publication/pool.ts`（公開讀取層），
本模組只回答「那一篇的封面是哪一張」。撤回、隔離、未發布的資料不會因此露出來。

## 想調整

- **不要某些圖當封面**：`clean.ts` 的 `JUNK_PATH`／`JUNK_NAME`／`JUNK_EXT` 是判斷式，
  照你的來源再加規則；`isBlockedImageHost` 可以整批排除某些網域。
- **換顯示位置或數量**：`web.tsx` 的 `SHOW_ON`（頁面）與 `?limit=`（1–24，預設 12）。
- **不要這個欄位、只要清理**：把 `site/modules/web.ts` 的 `coversWeb` 去掉，`server.ts` 保留
  （清理任務與接口繼續運作）。

## 已知取捨

- 封面欄是**瀏覽器載入後**才填上的（模組沒有頁面層的 loader，伺服器端拿不到資料就不佔位），
  所以第一屏會先看到內容、再看到封面欄。要改成伺服器端渲染得動引擎的 root loader。
- 封面一律經 `/api/img-proxy` 顯示，簽名有效期 48 小時；代理取圖的流量上限見 `.env`。
