# fanza：官方新作、官方封面與正版入口

成人影片產業的官方情報大半在 FANZA（DMM）手上，而那些頁面從臺灣看不到（地區限制）。這個模組改用
**DMM Web Service API v3（FANZA 聯盟）**：官方自己提供的商品資料，包含片商、廠牌、系列、出演者、
型別、發售日、價格、**官方封面圖**，以及**聯盟網址**。

推進來之後，每一部作品就是站上的一條資料，和其他信源一樣經過預篩、兩次評分、結構抽取、寫作與歸組：

| 站上的位置 | 來自 API 的什麼 |
|---|---|
| 原文連結（卡片、詳情頁、RSS、API、MCP） | `item.URL` —— 聯盟網址，讀者點到的是 FANZA 官方商店 |
| 封面圖 | `item.imageURL.large`，放進資料的 media |
| 標題、摘要的材料 | `item.title` 與商品資訊（片商／廠牌／系列／出演者／型別／發售日／價格） |
| 發售日 | `item.date`（日本時間 +09:00） |

## 申請憑證（一次就好）

1. 註冊 DMM 帳號，加入 **FANZA アフィリエイト**：<https://affiliate.dmm.com/>
2. 在後臺申請 **API 利用登録**，取得 `api_id`：<https://affiliate.dmm.com/api/>
   （這個說明頁從臺灣可能被地區限制；看不到時掛一次日本代理。）
3. 在同一頁取得你的 `affiliate_id`，形如 `xxxxxxxx-990`。
4. 兩者填進 `.env`：

   ```dotenv
   FANZA_API_ID=你的 api_id
   FANZA_AFFILIATE_ID=你的 affiliate_id
   # 選填：商品分類，預設 videoa（FANZA 動畫）；可改 videoc（出租）等
   # FANZA_FLOOR=videoa
   # 選填：每次抓幾筆，預設 30，上限 100
   # FANZA_HITS=30
   ```

5. 重啟 worker。之後每 6 小時跑一次（排程名 `fanza.items`，後臺「執行」頁看得到結果與件數）。

沒填憑證時任務不會失敗：它回報「未設定」然後什麼都不做。

## 條款與禮貌

- **聯盟連結不得加工**：`item.URL` 是官方給的網址，原樣使用。改寫或去除聯盟引數會違反聯盟規約，也拿不到分潤。
- **商品資訊不得自行改寫**：資料原樣保留在連結與素材裡，站上寫的中文標題與摘要另外標示為本站的說法。
- 圖片的使用範圍、出處標示與快取期限請照 DMM Web サービス利用規約辦理；本站不重製檔案，圖片只做代理顯示。
- 一次執行一個請求，不併發、不重試打；`FANZA_HITS` 不要為了多抓而拉到上限。

## 停用

從 `site/modules/index.ts` 與 `site/modules/server.ts` 的兩份清單去掉這個模組，重新建置即可；
已經推進來、標在那個信源下的資料不會消失（要清就自己在後臺暫停 `fanza-new` 這個信源）。
